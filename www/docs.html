Arduino Web IDE
使い方・しくみ

ブラウザーでArduinoのプログラムを書き、コンパイルして、対応するボードに書き込むためのIDEです。画面の操作方法から、コンパイルサーバーとの関係まで順番に説明します。

このページは一般利用者向けの案内です。サーバーの設置・ネットワーク公開・トークン発行は、管理者や先生の案内に従ってください。

このIDEについて

Arduino Web IDEは、ブラウザー上のエディターと、Arduino CLIを動かすコンパイルサーバーを組み合わせて動作します。アプリのインストールをせずにコードを編集できますが、すべての処理がブラウザーだけで完結するわけではありません。

ブラウザーで行うこと

コード編集、スケッチ管理、バックアップ、対応ブラウザーでのシリアル通信とボードへの書き込みを行います。

コンパイルサーバーで行うこと

コードのコンパイル、ボード情報の取得、ボードパッケージやライブラリの検索・管理を行います。

使う前に

対応画面: このIDEはパソコン（デスクトップ／ノートPC）の画面での利用を前提としています。スマートフォンなどモバイル端末での表示・操作は最適化および動作保証の対象外です。パソコンから利用してください。
  • IDEを開くためのURLと、必要に応じて先生・管理者から配布されたコンパイルサーバーURL／生徒用アクセストークンを用意します。配布リンクがある場合は、それを開くと設定が入力されます。
  • コンパイルにはコンパイルサーバーへの接続が必要です。サーバーのURLやトークンがわからない場合は、管理者に確認してください。
  • ボードへの直接書き込みとシリアルモニターには、Web Serial APIに対応したブラウザー（ChromeまたはEdge）と安全な接続（通常はHTTPS）が必要です。
  • ボードをUSBでコンピューターにつなぎ、OS側で認識される状態にします。ブラウザーがポート選択を求めたら、対象のボードを選びます。
  • 書き込み対応はボードによって異なります。IDEに「ブラウザー書き込み未対応」と表示されるボードは、コンパイル結果をダウンロードして別の書き込み方法を使います。
安全上の注意: 管理者用トークンはボードパッケージやライブラリの変更に使えるため、他の人に共有しないでください。通常の利用では生徒用トークンを使います。

基本の使い方

  1. サーバーに接続する
    先生から配布された設定リンクを開くか、左側の「ヘルパー設定」でサーバーURLと生徒用トークンを入力して保存します。接続状態は画面下のステータスバーで確認できます。
  2. ボードを選ぶ
    画面上部の「ボード」から、実際に使用するArduinoボードを選びます。コンパイル結果は選択中のボード向けに作られます。
  3. スケッチを作成・編集する
    「新規」からスケッチを作成し、テンプレートを選びます。エディターにプログラムを書き、必要ならタブの「＋」からヘッダーや追加のソースファイルを作成します。
  4. コンパイルして確認する
    「検証」を押すか Ctrl+Enter を押します。進捗やエラーは下部の「コンソール」に表示されます。エラーが出た場合は、表示されたファイル名・行番号とメッセージを確認します。
  5. ボードに書き込む
    対応ボードをUSB接続し、「書き込み」を押します。コンパイル後にポートを選び、処理が完了するまでケーブルを抜かないでください。ボードが未対応の場合は、画面に案内されるダウンロード結果を使ってください。
  6. 必要に応じてシリアルを確認する
    「シリアル」または接続状態の表示を押し、ポートとボーレートを設定します。スケッチ側の Serial.begin(...) と同じボーレートを選ぶと、送受信内容を確認できます。
  7. 作品をバックアップする
    「バックアップ」からスケッチをZIP形式で書き出せます。別のブラウザーや端末で使う場合、ブラウザー内の保存データは自動で移らないため、定期的なバックアップをおすすめします。
コンパイルと書き込みは別の段階です。コンパイルが成功しても、ポート選択・USB接続・書き込み対応などの理由で書き込みが失敗することがあります。

画面の見方

場所・ボタンできること
上部「ボード」対象のボードを選択します。選択したボード名は下部ステータスにも表示されます。
「検証」現在のスケッチをサーバーでコンパイルし、結果をコンソールに表示します。
「書き込み」コンパイル後、対応するボードへブラウザーから書き込みます。
「新規」「開く」「保存」スケッチ作成、ファイルの読み込み、現在の編集内容の保存を行います。
左側「スケッチブック」このブラウザーに保存されたスケッチを切り替えます。名前変更・複製・書き出しなどはスケッチの操作メニューから行います。
「ボード管理」「ライブラリ」サーバーにあるボードパッケージやライブラリを管理します。検索・追加・削除には管理者権限が必要です。
下部「コンソール」コンパイルや書き込みの進捗、成功・エラーの詳細を確認します。
下部「シリアルモニター」ボードとシリアル通信を行います。ブラウザーのポート許可が必要です。
下部ステータスバー処理状態、選択中のボード、シリアル接続、カーソル位置などを確認します。「ヘルパー」の表示から接続設定を開けます。
右上の設定・テーマエディターの表示設定や自動保存間隔を調整し、ライト／ダークテーマを切り替えます。OSの動きを抑える設定に加えて、設定からアニメーションを減らすこともできます。

しくみと保存先

画面とコンパイルサーバーは別々に動作し、ブラウザーからネットワーク越しに必要な処理を依頼します。

ブラウザーで編集→サーバーへコンパイル依頼→結果をブラウザーで確認→USB経由で書き込み

どこに何が保存されるか

  • スケッチとIDE設定: 現在のブラウザーのIndexedDBに保存されます。同じ端末でも、別ブラウザー・別ブラウザープロファイル・別サイトURLとは共有されません。ブラウザーのデータを消すと失われる場合があります。
  • コンパイル処理: サーバーが受け取り、コンパイル用の作業領域で処理します。コンパイルしたソースはサーバーへ送信されるため、組織や管理者の利用ルールに従ってください。
  • ボードパッケージとライブラリ: コンパイルサーバー側で共有管理されます。個々の利用者のブラウザーだけにインストールされるものではありません。
  • 物理ボードへの書き込み・シリアル通信: 対応ブラウザーからUSBポートを直接利用します。コンパイルサーバーがUSB機器に接続するわけではありません。
  • バックアップ: スケッチをZIPに書き出し、端末のダウンロード領域などに保管できます。大切なコードはIDE内の自動保存だけに頼らず、別の場所にも保存してください。

トークンと権限

種類主な用途取り扱い
生徒用トークンコンパイル、ボードやライブラリ情報の閲覧など配布された範囲で使用し、公開掲示板やソースコードに貼り付けないでください。
管理者用トークンボードパッケージやライブラリの追加・削除、管理画面の利用管理者だけが使用します。生徒や一般利用者に配布しないでください。

サーバーのURLや利用可能な機能は、設置者の構成によって異なります。配布リンクや接続先に変更があった場合は、管理者から最新の案内を受け取ってください。

困ったとき

コンパイルサーバーに接続できない

ヘルパー設定でURLとトークンを確認します。ネットワークに接続できるか、サーバーが起動しているか、URLの変更がないかを管理者に確認してください。HTTPSのIDEから一般のHTTPサーバーへ接続すると、ブラウザーに拒否されることがあります。

認証エラー・トークンが正しくないと表示される

トークンの種類と入力ミスを確認してください。期限切れや再発行後の古いトークンは使えません。管理者用トークンが必要な操作を行っている場合は、管理者に相談してください。管理者トークンを生徒用の欄に入力して共有しないでください。

コンパイルは成功するが、書き込みができない

USBケーブルがデータ通信に対応しているか、ボードが接続されているか、書き込み対象のボードが選ばれているかを確認します。ChromeまたはEdgeでHTTPSページを開き、ポート選択ダイアログで正しい機器を選んでください。ボードによってはブラウザーからの直接書き込みに対応していません。

シリアルモニターが使えない

Web Serial対応ブラウザーを使っているか、ページをHTTPSまたはlocalhostで開いているかを確認します。ポートの許可が必要です。ボーレートはスケッチ側の設定と一致させてください。

ライブラリが見つからない、または追加できない

ライブラリ管理で検索し、表示された対象を確認します。ライブラリの追加・削除は管理者権限が必要なため、生徒用トークンでは操作できない場合があります。利用したいライブラリ名を管理者に伝えてください。

以前のスケッチが表示されない

正しいブラウザー、ブラウザープロファイル、IDEのURLを使っているか確認します。スケッチはそのブラウザーのローカル保存領域にあります。別端末に移行する場合は、事前にZIPバックアップを書き出して読み込んでください。

コンパイルエラーが出る

コンソールに表示されたエラーの行番号とメッセージを確認し、選択したボードや必要なライブラリが正しいか調べます。問題が続く場合は、エラー全文、ボード名、行った操作を添えて管理者やサポート担当者に相談してください。トークンや秘密情報は共有しないでください。

用語集

スケッチ

Arduinoのプログラムと、そのプログラムに付属するファイルをまとめたものです。

コンパイル

プログラムを、選択したボードが実行できる形式へ変換する処理です。

書き込み

コンパイルしたプログラムをUSBなどを通じてボードへ転送する処理です。

コンパイルサーバー（ヘルパー）

Arduino CLIを動かし、コンパイルや共有パッケージ管理を行うサーバーです。

ボードパッケージ（コア）

特定のボード向けにコンパイルするための定義やツールの一式です。

シリアルモニター

USBシリアル通信を使って、ボードとの文字データの送受信を確認する画面です。

このガイドはIDEの一般的な使い方を説明しています。ボード、ネットワーク、権限、書き込み方式によって利用できる範囲は異なります。
