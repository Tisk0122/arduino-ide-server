Arduino Web IDE
使い方・しくみ

ブラウザーでArduinoのプログラムを書き、コンパイルして、対応するボードに書き込むためのIDEです。画面の操作方法から、コンパイルサーバーとの関係まで順番に説明します。

このページは一般利用者向けの案内です。サーバーの設置・ネットワーク公開・トークン発行は、サービス管理者の案内に従ってください。

このIDEについて

Arduino Web IDEは、ブラウザー上のエディターと、Arduino CLIを動かすコンパイルサーバーを組み合わせて動作します。Arduino Cloud Editorとは別のサービスで、このIDEではコンパイルサーバーとブラウザーのWeb Serial APIを使います。ブラウザーからそのまま利用でき、対応ブラウザーではアプリとしてインストールできます。すべての処理がブラウザーだけで完結するわけではありません。

ブラウザーで行うこと

コード編集、スケッチ管理、バックアップ、対応ブラウザーでのシリアル通信とボードへの書き込みを行います。

コンパイルサーバーで行うこと

コードのコンパイル、ボード情報の取得、ボードパッケージやライブラリの検索・管理を行います。

使う前に

対応画面: このIDEはパソコン（デスクトップ／ノートPC）の画面での利用を前提としています。スマートフォンなどモバイル端末での表示・操作は最適化および動作保証の対象外です。パソコンから利用してください。
  • IDEを開くためのURLと、必要に応じてサービス管理者から配布されたコンパイルサーバーURL／IDE用アクセストークンを用意します。配布リンクがある場合は、それを開くと設定が入力されます。
  • コンパイルにはコンパイルサーバーへの接続が必要です。サーバーのURLやトークンがわからない場合は、管理者に確認してください。
  • ボードへの直接書き込みとシリアルモニターには、Web Serial APIに対応したブラウザー（ChromeまたはEdge）と安全なコンテキスト（通常はHTTPS。ローカル開発ではlocalhostも利用できます）が必要です。
  • 初回起動時に表示される「Arduino Web IDEへようこそ」で「USBポートを許可」を押し、ブラウザーの選択画面から接続中のボードを選びます。複数台使う場合は1台ずつ許可してください。一度許可したポートは、ブラウザーのサイト設定で許可を取り消すまで再利用できます。
  • 書き込み対応はボードによって異なります。IDEに「ブラウザー書き込み未対応」と表示されるボードは、コンパイル結果をダウンロードして別の書き込み方法を使います。
安全上の注意: 管理者用トークンはボードパッケージやライブラリの変更に使えるため、他の人に共有しないでください。通常の利用ではIDE用トークンを使います。

インストールとオフライン利用

初回起動時に表示される案内からインストールをおすすめします。後からは「設定」の「アプリのインストール」から実行できます。HTTPSでIDEを開くと、対応ブラウザーではブラウザーのメニューからもインストールできます。初回はオンラインでIDEを開いてください。

一度読み込んだ後は、オフラインでもIDEの画面を開き、ブラウザー内に保存されたスケッチの編集・保存ができます。画面下部にオフライン状態が表示されます。コンパイル、サーバーとの同期、ライブラリ管理はネットワーク接続が戻るまで利用できません。書き込みにはコンパイル結果と対応するUSB接続も必要です。

保存先: オフライン編集はこのブラウザーのローカル保存領域を使用します。他の端末との同期やバックアップの代わりにはならないため、大切なスケッチは別途エクスポートしてください。

基本の使い方

画面右上の「ヘルプ」から、操作箇所を明るく示しながらIDEの基本操作を順番に確認できるチュートリアルをいつでも開始できます。案内中にボード書き込みやシリアル接続などの操作は実行されません。

  1. サーバーに接続する
    サービス管理者から配布された設定リンクを開くか、左側の「ヘルパー設定」でサーバーURLとIDE用トークンを入力して保存します。接続状態は画面下のステータスバーで確認できます。
  2. ボードを選ぶ
    画面上部の「ボード」から、実際に使用するArduinoボードを選びます。ステータスバーにはUSB機器の検出状態が表示されます。USB識別情報から機種を特定できる場合は候補が表示されますが、スケッチの設定は自動変更されません。内容を確認して「検出したボードを適用」を押すか、一覧から手動で選んでください。コンパイル結果は選択中のボード向けに作られます。
  3. スケッチを作成・編集する
    「新規」からスケッチを作成し、テンプレートを選びます。エディターではArduino API・C++キーワード・スケッチ内の名前が候補表示され、上下キーで選択してEnterまたはTabで挿入できます。候補には関数の引数形式も表示されます。Ctrl+Spaceで候補を手動表示でき、設定から候補表示をオン／オフできます（初期設定はオン）。「整形」またはShift+Alt+FでC/C++のインデントを整え、「履歴」からこのブラウザーに保存された過去の編集内容を復元できます（最大20件）。ツールバー右側の「A−」「A＋」で文字サイズをすぐに変更できます。引用符や括弧を入力すると閉じる記号も自動で挿入されます。必要ならタブの「＋」からヘッダーや追加のソースファイルを作成します。
  4. コンパイルして確認する
    「検証」を押すか Ctrl+Enter を押します。進捗やエラーは下部の「コンソール」に表示されます。エラーが出た場合は、表示されたファイル名・行番号とメッセージを確認します。
  5. エラーのヒントを確認する
    設定で「コンパイルエラーの自動ヘルプ」を有効にすると、コンパイル失敗時にコンソール上部へ折りたたまれたヒントが表示されます。見出しを開くと原因候補と確認方法を確認できます。初期設定はオフです。該当するファイルの行番号にはエラーマーカーが表示され、クリックするとその行へ移動します。自動判定のため、必ず元のエラー出力も確認してください。
  6. ボードに書き込む
    対応ボードをUSB接続し、「書き込み」を押します。コンパイル後にポートを選び、処理が完了するまでケーブルを抜かないでください。ボードが未対応の場合は、画面に案内されるダウンロード結果を使ってください。
  7. 必要に応じてシリアルを確認する
    「シリアル」または接続状態の表示を押し、ポートとボーレートを設定します。スケッチ側の Serial.begin(...) と同じボーレートを選ぶと、送受信内容を確認できます。「プロッター」に切り替えると、改行で区切った数値や temperature:23.5, humidity:48 形式の値を最大300サンプルのグラフで確認できます。
  8. スケッチをバックアップする
    「バックアップ」からスケッチをZIP形式で書き出せます。別のブラウザーや端末で使う場合、ブラウザー内の保存データは自動では移行されないため、定期的なバックアップをおすすめします。
コンパイルと書き込みは別の段階です。コンパイルが成功しても、ポート選択・USB接続・書き込み対応などの理由で書き込みが失敗することがあります。
USB検出と権限について: ブラウザーのセキュリティ仕様により、ページを開いただけでUSBポートを一括許可させることはできません。初回案内のボタンを押して選択画面を開き、ポートを1台ずつ許可してください。許可はこのサイトに保存され、ブラウザーのサイト設定から取り消せます。Chrome / Edgeと安全なコンテキスト（通常はHTTPS。ローカル開発ではlocalhostも利用できます）が必要です。IDEの表示はUSBの接続・切断イベントに応じて更新しますが、ブラウザーのポート選択画面はページからリアルタイム更新できません。抜き差し後に一覧が変わらない場合は、選択画面を閉じてからもう一度開いてください。IDEが表示する台数は許可済みポートの数であり、物理的に接続中の台数とは限りません。複数ポートが許可されていても、機種を識別できたボードが1種類だけならその候補を表示します。異なる複数のボードを識別した場合や、USBシリアル変換器から機種を特定できない場合は手動選択してください。候補が表示されてもスケッチのボード設定は自動変更されず、利用者が適用を選びます。自動検出はシリアル通信の自動接続や書き込みを行うものではありません。カメラ・マイクなど、このIDEに不要な権限は要求しません。

上部「ボード」対象のボードを選択します。選択したボード名は下部ステータスにも表示されます。
「検証」現在のスケッチをサーバーでコンパイルし、結果をコンソールに表示します。
「書き込み」コンパイル後、対応するボードへブラウザーから書き込みます。
「新規」「開く」「保存」スケッチ作成、ファイルの読み込み、現在の編集内容の保存を行います。
左側「スケッチブック」このブラウザーに保存されたスケッチを切り替えます。右端の境界をドラッグするか、境界にフォーカスして左右キーを押すと幅を調整できます。名前変更・複製・書き出しなどはスケッチの操作メニューから行います。
「ボード管理」「ライブラリ」サーバーにあるボードパッケージやライブラリを管理します。検索・追加・削除には管理者権限が必要です。

下部「シリアルモニター」ボードとシリアル通信を行います。ブラウザーのポート許可が必要です。
下部ステータスバー処理状態、選択中のボード、シリアル接続、カーソル位置などを確認します。「ヘルパー」の表示から接続設定を開けます。
右上の設定・テーマエディターの表示設定や自動保存間隔を調整し、コード入力候補の表示をオン／オフにして、ライト／ダークテーマを切り替えます。OSの動きを抑える設定に加えて、設定からアニメーションを減らすこともできます。

しくみと保存先

画面とコンパイルサーバーは別々に動作し、ブラウザーからネットワーク越しに必要な処理を依頼します。

ブラウザーで編集→サーバーへコンパイル依頼→結果をブラウザーで確認→USB経由で書き込み

どこに何が保存されるか

現在の保存先は画面下部のステータスバーに表示されます。ログイン中はアカウントのクラウドとこのブラウザー、未ログイン時はこのブラウザーのみです。

  • スケッチとIDE設定: このIDEでは現在のブラウザーのIndexedDBに保存されます。Arduino CLI / Arduino IDEでいうSketchbook（ユーザーディレクトリ）とは別の保存場所です。同じ端末でも、別ブラウザー・別ブラウザープロファイル・別サイトURLとは共有されません。ブラウザーのデータを消すと失われる場合があります。
  • アカウントにログイン中のスケッチ: アカウントのサーバー領域にも同期されます。同じアカウントでログインすると、別の端末からも利用できます。既存のブラウザー内のスケッチは、アカウント画面から取り込んだ場合に同期対象になります。
  • コンパイル処理: コンパイル時にはスケッチがコンパイルサーバーへ送信され、サーバー上の作業領域で処理されます。組織や管理者の利用ルールに従ってください。
  • ボードパッケージとライブラリ: コンパイルサーバー側で共有管理されます。個々の利用者のブラウザーだけにインストールされるものではありません。
  • 物理ボードへの書き込み・シリアル通信: 対応ブラウザーからUSBポートを直接利用します。コンパイルサーバーがUSB機器に接続するわけではありません。
  • バックアップ: スケッチをZIPに書き出し、端末のダウンロード領域などに保管できます。大切なコードはIDE内の自動保存だけに頼らず、別の場所にも保存してください。

アカウントとスケッチの同期

アカウント画面からユーザー名とパスワードで新規登録し、ログインできます。ログイン中のスケッチはアカウントのサーバー領域に同期され、同じアカウントで別の端末からも利用できます。ブラウザーに保存済みのスケッチを取り込む場合は、アカウント画面で「このブラウザーの未登録スケッチをアカウントへ取り込む」を選んでください。

スケッチの閲覧について: スケッチはアカウントごとに分けて保存されます。ただし、管理者用トークンを持つ管理者は、管理コンソールから登録ユーザーのスケッチ一覧と内容を閲覧できます。個人情報、パスワード、その他の秘密情報はスケッチに含めないでください。

ログインセッションは12時間で期限切れになります。パスワードを変更すると、他の端末を含めてすべてのセッションが終了します。メールアドレスによるパスワード再設定機能はありません。パスワードは安全に管理し、第三者と共有しないでください。

サーバー障害や運営終了に備え、大切なスケッチはZIPにも書き出して別の場所に保管してください。サーバーのURLや利用できる機能は、設置者の構成によって異なります。

トークンと権限

種類主な用途取り扱い
IDE 用トークンコンパイル、ボードやライブラリ情報の閲覧など公開サイトやリポジトリに掲載しないでください。
管理者用トークンボードパッケージやライブラリの追加・削除、管理画面の利用管理者だけが使用します。一般利用者に配布しないでください。

困ったとき

コンパイルサーバーに接続できない

ヘルパー設定でURLとトークンを確認します。ネットワークに接続できるか、サーバーが起動しているか、URLの変更がないかを管理者に確認してください。HTTPSのIDEから一般のHTTPサーバーへ接続すると、ブラウザーに拒否されることがあります。

「トークンが正しくありません」と表示される

トークンの種類と入力ミスを確認してください。期限切れや再発行後の古いトークンは使えません。管理者用トークンが必要な操作を行っている場合は、管理者に相談してください。管理者トークンをIDE用欄に入力して共有しないでください。

コンパイルは成功するが、書き込みができない

USBケーブルがデータ通信に対応しているか、ボードが接続されているか、書き込み対象のボードが選ばれているかを確認します。ChromeまたはEdgeの安全なコンテキスト（通常はHTTPS。ローカル開発ではlocalhostも利用できます）で開き、ポート選択ダイアログから正しい機器を選んでください。ダイアログにArduinoがない場合は、いったん閉じてUSBを挿し直してから、書き込みボタンを押して開き直します。ボードによってはブラウザーからの直接書き込みに対応していません。

AVRボードの書き込みに失敗した場合、コンソールにブラウザー情報、許可済みポートと選択ポートのUSB VID/PID、書き込みが止まった段階を記録します。コンソールを消さず、診断行とエラー全文を管理者に伝えてください。VID/PIDが取得できない、または機種を特定できないUSBシリアル変換器の場合、ブラウザーからボード機種を確定することはできません。

シリアルモニターが使えない

Web Serial対応ブラウザーを使っているか、ページをHTTPSまたはlocalhostで開いているかを確認します。ポートの許可が必要です。ボーレートはスケッチ側の設定と一致させてください。

ライブラリが見つからない、または追加できない

ライブラリ管理で検索し、表示された対象を確認します。ライブラリの追加・削除は管理者権限が必要なため、IDE用トークンでは操作できません。利用したいライブラリ名を管理者に伝えてください。

以前のスケッチが表示されない

正しいブラウザー、ブラウザープロファイル、IDEのURLを使っているか確認します。スケッチはそのブラウザーのローカル保存領域にあります。別端末に移行する場合は、事前にZIPバックアップを書き出して読み込んでください。

コンパイルエラーが出る

コンソールに表示されたエラーの行番号とメッセージを確認し、選択したボードや必要なライブラリが正しいか調べます。問題が続く場合は、エラー全文、ボード名、行った操作を添えて管理者やサポート担当者に相談してください。トークンや秘密情報は共有しないでください。

用語集

スケッチ

Arduinoのプログラムと、そのプログラムに付属するファイルをまとめたものです。

コンパイル

プログラムを、選択したボードが実行できる形式へ変換する処理です。

書き込み

コンパイルしたプログラムをUSBなどを通じてボードへ転送する処理です。

コンパイルサーバー（ヘルパー）

Arduino CLIを動かし、コンパイルや共有パッケージ管理を行うサーバーです。

ボードプラットフォーム

Arduino CLIでは、ボード定義やビルド設定、必要なツールなどを含む一式をplatformと呼びます。coreはその中の構成要素で、platformと同じ意味ではありません。このIDEの管理画面では「ボードパッケージ」と表記しています。

シリアルモニター

USBシリアル通信を使って、ボードとの文字データの送受信を確認する画面です。

このガイドはIDEの一般的な使い方を説明しています。ボード、ネットワーク、権限、書き込み方式によって利用できる範囲は異なります。
