      Arduino Web IDEへようこそ
      
    

    

      
まずはサーバー接続を確認し、スケッチをコンパイルしてみましょう。

      
    
        
  1. 先生から配布リンクを受け取っている場合は、そのリンクからIDEを開きます。
    2. 
        
  2. サーバー接続が必要な場合は、先生から受け取ったURLと生徒用トークンを設定します。
    3. 
        
  3. 「新規」でスケッチを作成し、「検証」でコンパイルします。
    4. 
      

      
スケッチはこのブラウザー内に保存されます。別の端末へ移すときは「バックアップ」でZIPを書き出してください。

      
使い方と画面のしくみを読む

    

    

      
      
    

  







  

    

      コンパイルサーバー設定
      
    

    

      

        
        
コンパイル、ボード・ライブラリの追加には arduino-helper サーバーが必要です。書き込みはブラウザ (Web Serial) から直接行います。

      

      

        
        
        
例: https://xxxx.example.com / http://192.168.3.7:8765
